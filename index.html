Behind the build

Behind the build

03

Movie Review Helpfulness

Language / ML

Finding the helpful signal in 50,000 movie reviews.

Python · scikit-learn · pandas

View on GitHub ↗

Behind the research

Investigates whether review text and metadata can predict which Amazon movie reviews receive helpful votes. Across 50,000 reviews, the analysis explores how review length, plot discussion, and emotional language relate to those votes, with follow-up experiments examining review age and existing votes.

In a three-person team, compared seven classifiers and baselines using TF-IDF and 11 engineered features. Scikit-learn pipelines fit preprocessing on training data, with model and threshold selection on validation data. Class-weighted logistic regression performed best on validation, reaching 0.617 average precision and 0.580 F1 on the held-out test set.
